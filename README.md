# Blackjack Game

A simple Blackjack game implemented in JavaScript.

## Description

This project is a simple Blackjack game built with HTML, CSS, and JavaScript. It allows you to play Blackjack against Marit. The goal is to get as close to 21 points as possible without going over it.

## Features

- Shuffled deck of cards fetched from an API.
- Interactive gameplay with hit and pass buttons.
- Modal dialog to display game results.

## Getting Started

To run this game on your local machine, follow these steps:

### Prerequisites

- Node.js: You need Node.js installed on your computer. You can download it from [nodejs.org](https://nodejs.org/).

### Installation

1. Clone the repository to your local machine:

   ```bash
   https://github.com/bal-rtv/blackjack-nav

   ```

2. Change into the project directory:

   ```bash
   cd blackjack-nav

   ```

3. Install project dependencies:

   ```bash
   npm install

   ```

4. Running the Game

   ```bash
   npm run dev

   ```

## How to Play

- Click the "Hit" button to draw a card and add it to your hand.
- Click the "Pass" button to end your turn.
- Marit will automatically play her turn.
- The game will display the result in a dialog when it's over.
